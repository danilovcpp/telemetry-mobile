Команды для воспроизведения:

```powershell
pwsh -NoProfile -File scripts/Validate-DesignSystem.ps1
dotnet restore TelemetryMobile/TelemetryMobile.csproj -p:TargetFrameworks=net10.0-android
dotnet build TelemetryMobile/TelemetryMobile.csproj -f net10.0-android -p:TargetFrameworks=net10.0-android -p:RuntimeIdentifier=android-x64 -p:EmbedAssembliesIntoApk=true --no-restore -m:1 -nr:false
dotnet build TelemetryMobile/TelemetryMobile.csproj -f net10.0-android -c Release -p:TargetFrameworks=net10.0-android -p:RuntimeIdentifier=android-arm64 --no-restore -m:1 -nr:false
```

Для каталога к Debug-команде добавляется `-p:DesignSystemShowcase=true`. Обычный запуск не использует этот параметр. Override TargetFrameworks в командах ограничивает проверку Android и не меняет сохранённый список платформ проекта.

В ограниченной среде упаковка и дочерние процессы MSBuild работали нестабильно, поэтому итоговые пакеты собраны с разрешением вне песочницы. Для прямой установки через adb включён EmbedAssembliesIntoApk: APK с Fast Deployment без развёрнутых IDE assemblies самостоятельно не запускается. Эти параметры проверки не внесены как новые production-настройки проекта.

## Эмулятор и поведение

Проверено на Pixel 7 / Android API 36, x86_64:

- Обычный запуск открывает Login, без шаблонного Dashboard и менеджера задач.
- Визуально проверены логотип, фон, типографика, поля и кнопка входа.
- RU → DE → EN переключаются на открытом экране; выбранный язык сохраняется при перезапуске.
- Пустые поля показывают локализованные ошибки; ввод убирает соответствующую ошибку. Пароль использует настоящий Entry с IsPassword.
- Проверен viewport 320 × 569 DIP (720 × 1280, density 360), font scale 1.5 и немецкий язык: текст переносится, поля и кнопка доступны при прокрутке.
- При открытой клавиатуре активное поле остаётся видимым; к кнопке входа можно прокрутить форму. На низком viewport декоративная волна скрывается.
- В showcase проверены палитра, типографика, loading/disabled/error, статусы, карточки устройств и сводки, строки метрик и событий. Длинные подписи палитры не обрезаются.
- Проверена команда DeviceCard: нажатие обновляет локализованный feedback в каталоге.
- После исправления зависимостей словарей запуск проходит без XamlParseException. Компиляция сама по себе не обнаруживала первоначальную ошибку области видимости StaticResource; теперь она дополнительно контролируется скриптом.

Снимки проверки и локальные APK находятся в `.artifacts/design/` (не версионируются). Исходные размеры экрана, density и font scale эмулятора после проверки восстановлены. Итоговый обычный запуск возвращён на Login.

## Ограничения

В исходном проекте отсутствовали авторизация и бизнес-экраны. Теперь по запросу добавлены demo-авторизация test/test, общий mock-источник, Devices, Device Details и Events. Настоящая серверная авторизация по-прежнему не подключена.

Не выполнены проверки на физических устройствах, других Android API, iOS, MacCatalyst и Windows, а также полный аудит TalkBack. Визуальная проверка эмулятора не является подтверждением работы на всех поддерживаемых платформах.
